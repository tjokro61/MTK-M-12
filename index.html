Modul Web App interaktif ini dirancang untuk mahasiswa Teknik Elektronika agar dapat memahami hubungan konversi matematika sudut serta karakteristik gelombang AC sinusoidal pada rangkaian listrik.

1. Konversi Satuan Sudut DEG ↔ RAD ↔ DMS

Memahami konversi satuan sudut secara dua arah (↔) antara Derajat Desimal (°), Radian (rad) — termasuk kelipatan π, dan DMS (Degree, Minute, Second).

Contoh Konversi Dasar:
  • 1 rad = 180° / π ≈ 57,2958°
  • 1° = π / 180 rad ≈ 0,017453 rad
  • 1° = 60' (menit)
  • 1' = 60" (detik)
  • 1° = 3600" (detik)
Derajat (°) ↔ Radian (rad/kπ) ↔ DMS (° ' ")
2. Phase Angle (Lead vs Lag) FASE φ

Memahami tanda sudut fase (φ) terhadap acuan standar gelombang y = A sin(ωt), serta menentukan kondisi Leading, In Phase, atau Lagging.

y = A sin(ωt + φ) → LEADING (+)
y = A sin(ωt) → IN PHASE (0)
y = A sin(ωt − φ) → LAGGING (−)

*Gelombang Leading mencapai puncak lebih awal (bergeser ke kiri), sedangkan Lagging mencapai puncak lebih lambat (bergeser ke kanan).

3. Parameter Sinusoidal AC GELOMBANG AC

Menganalisis besaran fisis tegangan/arus sesaat pada rangkaian AC, meliputi amplitudo, periode, frekuensi, dan kecepatan sudut.

  • A : Amplitudo Puncak (Volt / Ampere)
  • T : Periode = 2π / ω (sekon)
  • f : Frekuensi = 1 / T (Hz)
  • ω : Kecepatan sudut = 2πf (rad/s)
